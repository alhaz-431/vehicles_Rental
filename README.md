# Vehicle Rental System

A web-based Vehicle Rental System that allows users to browse available vehicles, make bookings, and manage rentals efficiently. This project demonstrates CRUD operations, authentication, and a responsive user interface.

---

## Live URL

*(Live deployment link will be available after Render/Railway deploy)*  
[Live Demo](https://github.com/alhaz-431/vehicles_Rental)

---

## Features

- Browse and search available vehicles
- User authentication (signup & signin)
- Book vehicles and manage rentals
- Admin dashboard to manage vehicles and bookings
- Responsive design for desktop and mobile

---

## Technology Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (if applicable)
